# DONAMANO — versione finale

Sito statico completo, pronto per GitHub Pages o altro hosting statico.

File principali:
- `index.html`
- `style.css`
- `script.js`

Il modulo usa FormSubmit via AJAX e inoltra le richieste a `guerini16marco@gmail.com`.

## Pubblicazione GitHub Pages
Carica/sostituisci **tutti e tre i file principali** nella radice del repository. Non caricare solo `index.html`.

Dopo il commit, GitHub Pages aggiornerà il sito automaticamente.

## Modulo
Al primo invio FormSubmit richiederà la verifica dell'indirizzo destinatario. Non serve creare un secondo sito né un backend.
